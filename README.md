# QuingKhaos' Development Suite

Personal collection of mods that I always use for mod development and testing. Why? Because I got tired of enabling every
single mod I use for testing by hand every time I needed to disable the whole mod list.

**But why is this on the mod portal?**

Because that's the sanest way to use it when you work with multiple machines and multiple Factorio installations or mod
directories.
